# HTML5 Canvas Drawing Application

## Project Description
This project is an interactive drawing application developed using HTML5 Canvas, CSS, and JavaScript. Users can draw on the canvas using mouse events, change brush colors, and clear the screen easily.

---

## Features
- Draw freely on the canvas
- Change brush colors
- Clear the canvas
- Smooth drawing with mouse events
- Simple and user-friendly interface

---

## Technologies Used
- HTML5
- CSS3
- JavaScript
- HTML5 Canvas API

---

## How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Run the `index.html` file in any web browser

---

## Mouse Events Used

| Event | Function |
|---|---|
| mousedown | Starts drawing |
| mouseup | Stops drawing |
| mousemove | Draws on canvas |
